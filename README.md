# CareerConnect

CareerConnect merupakan aplikasi berbasis web yang membantu fresh graduate dalam mencari informasi lowongan pekerjaan, mengelola profil profesional. Aplikasi ini menyediakan fitur pembuatan profil dan CV digital, pencarian lowongan berdasarkan bidang pekerjaan, penyimpanan lowongan favorit, serta pemantauan status lamaran.
